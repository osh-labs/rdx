Connect your Reddit account

Reddit disabled unauthenticated access in May 2026, so this instance reads Reddit through your own account. It is a one-time setup.

  1. Open reddit.com/prefs/apps and choose create another app.
  2. Name it anything. Select installed app as the type.
  3. Set the redirect URI to exactly:
  4. Create it, then copy the client ID — the string just under the app name, not the one labelled secret.

An installed app is a public client, so there is no secret to enter or store. The client ID is kept in this browser only.
